# إدارة متابعة الأنظمة الرقمية

لوحة PMO تنفيذية مستقلة لوكالة العمرة، مبنية كواجهة ثابتة قابلة للنشر عبر GitHub Pages، مع قاعدة بيانات أسبوعية في `data.json`.

## ما تعرضه اللوحة

- إجمالي محفظة المتطلبات المبلغ عنه: 112.
- فصل خط الأساس الموثق (74) عن الإضافات تحت المطابقة (38).
- فلترة حسب الأسبوع والمحفظة والحالة والأولوية والبحث النصي.
- بطاقات المحافظ: آخر تحديث، الإجراء القادم، الدعم المطلوب، المخاطر، المالك، والتقدم.
- غرفة متابعة تفصيلية لكل محفظة، تشمل سجل الأعمال والأدلة وأصحاب المصلحة والقرارات.
- سجل حوكمة رأسي يوضح المتابعة والتنفيذ والموافقات والتشغيل والتصعيد.
- سجل مخاطر وتصعيد، وقياس قيمة مكتسبة `PV / EV / SV / SPI` مع حجب `CV / CPI` عند غياب التكلفة الفعلية.
- رسوم Canvas متحركة دون مكتبات خارجية، مع دعم `prefers-reduced-motion`.
- منهجيات PMO: Portfolio Governance، Stage-Gate، RAG، RAID، والإغلاق المبني على الدليل.

## التشغيل المحلي

أي خادم ملفات ثابت يكفي، مثال:

```powershell
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## التحديث الأسبوعي

1. أضف الأسبوع داخل `weeks` في `data.json`.
2. حدّث `weeks` في كل محفظة ظهرت في الفترة.
3. حدّث `lastUpdate` و`next` و`support` و`risk` و`progress`.
4. أضف سجل الأعمال التفصيلي وأصحاب المصلحة في `portfolio-details.json` وفق نموذج محفظة الإعاشة.
5. لا تغيّر إجمالي المتطلبات إلا من مصدر معتمد، وافصل دائماً البنود الموثقة عن البنود تحت المطابقة.

## النشر

المشروع لا يحتاج عملية build. انشر الجذر مباشرة عبر GitHub Pages.
